# Pokédex Tracker — improvement plan, outcomes (2026-11-10)

The work order of 2026-11-10 (a read-only review at `3381fe5`, v1.8) and what became of each item. The owner asked
for every item, owner decisions included, in one go; where an item offered a choice, the choice made is stated.

## Baseline

Before any change: `npm run lint`, `format:check`, `knip`, `typecheck` and `npm test` all passed (Vitest 600 passed,
1 skipped; sync server 23/23). After: Vitest 662 passed, 1 skipped (651 unit, 11 component); sync server 34/34; lint
(now type-aware), format, knip, typecheck and the build clean.

Not run here: Docker is not installed on this machine, so the image build and `deploy/smoke-test.sh` were not run
locally — CI runs both before publishing. `npm run e2e` and `npm run screenshots` were not run as part of this record.

## Phase 1 — Security

| # | Outcome |
| --- | --- |
| S1 | **Done.** `createLoginLimiter` in `server.js` counts failures across all clients: 10 in 10 minutes lock login (429, `Retry-After`, 30 s doubling to 15 min), cleared by a success, driven by the injected `now`. Both login screens show and count down the wait. Tests: lock, release with doubling to the cap, reset. Documented in `self-hosting.md` (Failed sign-ins), with the lock-out trade-off and the Cloudflare rule as a third layer. nginx's limit now answers 429. |
| S2 | **Done.** Values equal to `.env.example`'s placeholders count as unset; `/health` lists them as `placeholders`; the login screen names them; `configWarnings()` logs placeholders, a `SYNC_TOKEN` under 32 characters and an `APP_PASSWORD` under 12. The server never exits. Upgrade note in the changelog. |
| S3 | **Done, owner decision taken: per-device sessions.** Login mints a 256-bit token; `sessions.json` keeps its SHA-256, a label (`deviceLabel()`), created and last-used times. `requireAuth` accepts a session or `SYNC_TOKEN`; sessions are keyed to the current `SYNC_TOKEN`, so rotating it signs everyone out. `/api/sessions`, `/api/sessions/:id/revoke`, `/api/logout`; Settings → Signed-in devices. "Rotating the token" is in `self-hosting.md` and `SECURITY.md`. |
| S4 | **Done.** `x-powered-by` off, `Cache-Control: no-store` on `/api` and `/health`, `server_tokens off`, `no-cache` on the SPA fallback. `smoke-test.sh` asserts each. |
| S5 | **Done.** `isLocalAddress()` / `isInsecureRemote()` with tests. Web: a warning line over HTTP to a non-local host. iOS: a non-local `http://` address is refused with the HTTPS explanation. |
| S6 | **Done.** Unticked "Also remove my data from this browser" in the sign-out confirmation: clears localStorage, sessionStorage, Capacitor Preferences and the `pokedex-saves` IndexedDB, then reloads. The copy says data stays otherwise. |
| S7 | **Done in part.** `HEALTHCHECK` on `/health`; `no-new-privileges` in compose. `cap_drop: [ALL]` **not added**: it could not be smoke-tested here (no Docker), and nginx and the entrypoint need several capabilities.
